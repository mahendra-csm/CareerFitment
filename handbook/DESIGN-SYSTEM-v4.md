# Design system v4: editorial brochure

v4 replaces the v3 "tinted card" look that read as AI-generated.

## What changed and why

| v3 problem | v4 answer |
|---|---|
| Dozens of pastel rounded cards with icons in tinted tiles | Square corners everywhere. Cards became editorial columns with a short colour bar and hairline rule. Icons are plain line icons, without tiles. |
| Colour scattered in small boxes | Colour sits in big fields: a full-width chapter-colour header band on every page, full-bleed tool and activity headers, chapter openers, quote bands and colour-coded tables. |
| Stat boxes | Big Poppins numerals between hairlines (annual-report style) |
| Callout boxes | Margin notes: a coloured rule with a label |
| Illustrative dimension charts | Each dimension page is built around the **real report page** for that dimension (sample Class 9–10 report), with numbered pins and a reading key |
| Report chapter used thumbnails | The scorecard page shows the real scorecard large, with 8 numbered pins and a key, and a roadmap of the deep-dive structure |
| No inspiration | 10 chapter-opener quotes, 11 in-page quote bands and one full-page photo quote spread |

The full-page quote spread replaces the separate Dr Rudrarup Gupta page. He remains on the committee wall.

## Colour

- **Brand:** red `#C72D35`, navy `#17243A`.
- **Accents:** blue `#2196C8`, purple `#7754B8`, green `#279B70`, orange `#F09A24`, gold `#E5B73B`.
- **Header bands:** white text on red, blue, purple, green and navy bands; navy text on orange and gold bands for contrast.

## Type

- Poppins Bold for titles, with the second line of a title in Medium.
- Inter for everything else.
- Labels are 7.6 pt tracked capitals.

## Canva

The Canva connector works, but this cloud environment's network policy blocks the Canva upload and media hosts (`www.canva.com`, `media.canva.com`, `export-download.canva.com`). Because of that, Canva's graphics and icon library cannot be placed into the book from here.

To fix this, add those hosts under **Allowed domains** in the environment's network settings. Alternatively, import the PDF in Canva with **Create a design → Import file**; every page becomes editable there.
