# v5 "Sales edition": what changed

The handbook is restructured as a product book that sells, built on the approved 10-page prototype (`sales.py` / `sales.css`).

## Visual system

- **Palette:** navy `#0E1A2E`, red `#D62F38` and white. Sun yellow `#FFC83D` is used only for accents on dark pages. The eight dimension colours appear only where they code the dimensions.
- **Type:** Poppins ExtraBold display titles. Every title's second line is red. Eyebrows are red, tracked capitals. Body text is Inter.
- **Screenshots:** solid offset blocks (navy or red) behind every screenshot, with no blur.
- **Chapter openers:** full-bleed navy pages with a huge red part number, a duotone school photo, an "In this part" route and a quote.
- **Tool and activity headers:** full-bleed navy or red.
